# Análise de Dados COVID-19 Brasil

Dashboard interativo para análise e visualização de dados da COVID-19 no Brasil.

## Sobre o Projeto

Este projeto é um dashboard web desenvolvido com Streamlit que apresenta análises e visualizações dos dados da COVID-19 no Brasil, incluindo:

- Evolução temporal de casos e óbitos
- Distribuição de casos por estado
- Análise comparativa entre estados
- Informações sobre prevenção e conscientização

## Tecnologias Utilizadas

- Python
- Streamlit
- Plotly
- Pandas

## Como Executar

1. Clone o repositório
2. Instale as dependências:
```bash
pip install -r requirements.txt
```
3. Execute o aplicativo:
```bash
streamlit run src/app.py
```

## Fonte dos Dados

- Ministério da Saúde
- Secretarias Estaduais de Saúde
- Brasil.io
